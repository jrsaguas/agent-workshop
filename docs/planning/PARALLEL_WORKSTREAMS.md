# Trabajo paralelo

La idea es aprovechar los conectores disponibles sin convertir ChatGPT en un cuello de botella.

## ChatGPT + GitHub
- Diseño de repositorio.
- Issues y PRs.
- Revisión de cambios.
- Documentación.
- Integración de archivos.

## Desktop Commander
- Crear estructura local.
- Ejecutar tests/builds.
- Inspeccionar entorno Windows.
- Probar Ollama.
- Probar runtimes PC/Android.

## Regla
Cada tarea local debe dejar evidencia reproducible: comando, resultado, archivo afectado y estado.

## Branching inicial
- main: estable.
- feat/*: funcionalidades.
- docs/*: documentación.
- runtime/*: runtimes.
- integration/*: integraciones.
