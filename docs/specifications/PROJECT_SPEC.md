# Especificación del producto

## 1. Producto
Agent Forge: entorno para crear agentes especializados con configuración visual y declarativa.

## 2. Entidades principales
- Agent
- Model Provider / Model
- Tool
- MCP Server / MCP Tool
- Skill
- Memory Provider
- Runtime
- Permission Policy
- Agent Graph
- Execution
- Evaluation
- Artifact / Version

## 3. Capacidades configurables
Razonamiento, planificación, ejecución, código, web, Git/GitHub, archivos, terminal, navegador, PC, Android, APIs, RAG, memoria, evaluación, reflexión, reintentos y delegación.

## 4. Composición
Un agente puede exponer operaciones a otro agente como herramientas y participar en grafos jerárquicos o dirigidos.

## 5. Portabilidad
La definición del agente se almacenará en un formato declarativo versionable y validado por schema.
