# Agent Forge

Agent Forge es un estudio para diseñar, configurar, guardar, ejecutar y conectar agentes especializados.

## Objetivo
Construir agentes como artefactos portables, versionables y componibles, separando agente, modelo, herramientas, MCP, skills, memoria, permisos y runtime.

## Principios
- Local-first cuando sea posible.
- Modelo y agente son entidades independientes.
- Capacidades y permisos son conceptos distintos.
- Todo agente debe poder versionarse y validarse.
- Seguridad y aprobación humana son parte del diseño.
- Multiagente como composición, no como acoplamiento.

## Ecosistema previsto
Agent Forge + Praxis Runtime + Memora + PC Runtime + Android Runtime + Web Runtime.
